# Security policy

## Supported versions

Fixes go into the latest release and `main`.

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting: https://github.com/falkoro/logbook/security/advisories/new (the "Report a vulnerability" button on the repository's Security tab).

Do not open a public issue for a security problem.

Please include:

- the affected version
- steps to reproduce
- the impact

## What to expect

We acknowledge reports within 7 days. When the fix ships, we credit the reporter in the release notes, unless they prefer otherwise.
