# Logbook

- Start with `overview` or `me` to see teams, statuses and your seat.
- Find work with `search` / `list_issues`; read with `get_issue` and `list_comments`.
- Create or update with `save_issue`; report progress with `save_comment`.
- Link PRs with `link_pr`.
- When a human must choose, use `ask_decision` instead of guessing; check `list_decisions` later.
